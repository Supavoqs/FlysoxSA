# FlySox SA — Online Store

Funky, colorful socks for men. Proudly South African. Built on **WordPress + WooCommerce**.

This repo contains everything needed to stand up the FlySox SA store: a custom WooCommerce theme, ready-to-import product data, and all approved brand copy and legal pages.

## What's in here

```
wp-content/themes/flysox-sa/   Custom WooCommerce theme (hero homepage, About Us template, color-swatch styling)
data/products-import.csv       3 sample products x 8 colorways, ready for WooCommerce's product importer
content/pages/                 Privacy Policy (POPIA) and Returns & Exchanges (CPA) copy
docs/SETUP.md                  Step-by-step store setup guide (plugins, attributes, import, shipping, launch checklist)
docs/CONTENT.md                Canonical brand copy: tagline, hero copy, About Us, product description template, color palette, SEO meta description
```

## Brand

- **Colors:** Fire Red, Electric Blue, Sunshine Yellow, Jungle Green, Ocean Teal, Charcoal Camo, Sunset Orange, Royal Purple

## Quick Start
See [`docs/SETUP.md`](docs/SETUP.md) for the full walkthrough. In short:
1. Install WordPress + WooCommerce + recommended plugins
2. Upload/activate the `flysox-sa` theme
3. Create the Color attribute + terms
4. Import `data/products-import.csv`
5. Set ZAR currency, tax, and shipping zones
6. Publish the Privacy Policy, Returns, and About Us pages
7. Go live 🔥
